# FoloToy EVA 音乐播放器

这是面向 FoloToy AI Passport（ESP32-C3、8 MB Flash）的音乐播放器，现已接入网络电台原型，当前源码版本为 `1.2.0-dev`。开机显示 NERV 图案并播放本地启动音；本地曲库保存在设备 Flash 中，用户可连接设备的开放 Wi-Fi 热点上传自己的音乐。

## 使用

1. 开机先保持背光关闭，NERV 图案绘制完成后点亮屏幕并播放启动音；结束后进入播放器。空曲库会显示 `NO TRACKS`。
2. 在本地播放器或网络电台长按 `DOWN`，停止播放并进入 EVA 热点页面。屏幕显示 `EVA-PLAYER-XXXX` 热点名。
3. 手机连接该热点，无需密码。浏览器打开 `http://192.168.4.1/`，选择音乐并上传。
4. 等页面提示传输完成，再在设备上长按 `DOWN` 退出传输页面。`OK` 播放/暂停，`UP`、`DOWN` 切歌。

长按 `UP` 在本地播放器与网络电台之间切换，模式自动保存。长按 `DOWN` 进入或退出热点页。长按 `OK` 打开 EVA 系统设置，可调整亮度、音量和自动熄屏，并查看实际固件版本号。音量为 0–100%，每次调整 5%，保存返回后下次开机沿用。

网页在手机浏览器中将音乐转为 12 kHz 或 8 kHz 单声道 FAM1/IMA ADPCM 后上传。单首最长 6 分钟、源文件最多 30 MB、转换后最多 2.5 MB，曲库最多 32 首；实际数量受剩余 Flash 空间限制。网页可以查看、删除歌曲，以及重新同步歌名图片。上传期间暂停播放，退出传输页面后从当前曲目开头播放。

完整出厂固件也可以预置歌曲：歌曲作为普通文件保存在同一个可写音乐分区，开机即可在曲库中看到，并可通过音乐管理页面删除、释放空间。删除后重启不会恢复；重新刷入含歌曲的完整出厂镜像才会恢复初始曲库。仅刷应用程序不会安装预置歌曲。生成和打包方法见[预置歌曲说明](docs/ASSET_PREPARATION.md#optional-deletable-factory-songs)。刷完整镜像会覆盖原有歌曲和设置。

其他页面修改曲库后，旧页面的删除／同步歌名请求会被拒绝并刷新列表，需要重新选择歌曲。删歌不再改名其他文件，重启允许文件槽位有空缺；新上传会复用空槽，因此可能插入列表前部。若删除在移除歌名图之后中断，歌曲仍能播放，可用“同步歌名”恢复标题。曲末等待期间进入设置调音量，不会取消自动下一曲；长按 `UP` 则切换播放模式。

设备固定文字、按钮及运行时英文和数字由构建者自备的字体在本地生成。上传网页随固件内置该字体的小型子集，手机打开页面后自动加载，用于网页文字和新歌名图，无需在手机上选择字体。子集未收录的字使用浏览器备用字体，重新同步歌名时页面会提示。已上传的旧歌名可点击“同步歌名”更新。字体原文件、生成的字形源码和网页字体子集均不上传 Git。

长按 OK 打开中文「系统设置」。上下键选择项目，短按 OK 编辑或确认，长按 OK 或选择「保存并返回」退出。「模式」切换本地播放器/网络电台；「亮度」为 10–100%；「音量」为 0–100%；「版本」只读显示当前固件版本；「自动熄屏」为常亮/15/30/60/120/300 秒；「网络设置」打开配网热点。熄屏只关闭背光，首个按键仅唤醒；模式与设置重启后保留。曲目结束后停留约 2 秒，再循环播放下一首。

播放器右上角“内部”旁的红条表示 CW2017 读取的电量：1–33% 一条、34–66% 两条、67–100% 三条；0% 或读数失败时不亮。约每 30 秒刷新一次。

音量0–70%保持原来的档位；70%以上提高，100%上限由0 dB调整为+6 dB，0%静音。本地播放器与网络电台共用该曲线。

## 当前电台状态（2026-11-01）

原有本地音乐、上传、删除和歌名同步功能保留。长按 OK，在「网络设置」中打开热点，通过首页独立的电台配网面板扫描 Wi-Fi，点选名称并输入密码。将「模式」改为「网络电台」并保存即可连接；选择「本地播放器」返回。当前收录大陆 19 个城市 89 路 MP3 电台。电台页沿用原播放器 EVA 框架：左上原「再生时间」文字区显示城市和电台序号，中央大框显示中文台名，下一框显示直播状态，最底部保留上台、播放、下台、暂停四格按钮，框间显示简短选台提示。双击 OK 选择城市再选择电台，列表内长按 DOWN 返回上一级；短按 UP/DOWN 换台、OK 播放/暂停，长按 UP 切换模式、DOWN 进入热点、OK 打开设置。电台页增加分类、选台提示与实际直播状态灯，连接或缓冲时不会误亮播放状态。城市列表和设置共用相同顶栏、电量框及面板；按键说明集中到设置的「操作说明」。中文使用本地生成的 Noto 字体子集，详见[电台开发文档](docs/EVA_RADIO.md)。

当前应用为 1,999,984 字节（0x1e8470），2 MiB 应用分区余 97,168 字节，静态 DRAM 余 112,356 字节。11 月 1 日应用单独烧录并校验通过；串口确认模式往返、热点进出、扫描、上传 1 首、设置保存、本地 12 kHz 和电台 44.1 kHz 输出。两个台站 HTTP 200，一段约一分钟窗口无重连；这些日志不代替新布局与实际听感确认，也不代表全部电台或长期稳定。完整主机回归：Python 32 通过／1 跳过，独立 C 程序 9 通过，JS 脚本 3 通过。详见[本轮实机记录](docs/HARDWARE_TEST_20261101.md)及[文档索引](docs/README.md)。

当前 Linux 电脑已安装的独立开发环境可通过 `.venv/bin/python tools/idf_linux.py --check` 检查，通过 `.venv/bin/python tools/idf_linux.py build` 构建。该入口检查路径并传递命令退出码，不自动安装依赖或生成缺失素材。

## 构建

本机已安装的Linux环境使用.venv/bin/python tools/idf_linux.py build size；新机器先按[硬件指南](docs/AI_HARDWARE_DEVELOPMENT_GUIDE.md)和[素材准备](docs/ASSET_PREPARATION.md)安装工具并生成素材。

使用 ESP-IDF 5.5.x。请自备有中日文字形、可在本机使用的字体与启动音；安装 Python 的 Pillow、fonttools 及 Node.js/npm，然后在构建前生成本地素材。克隆仓库后必须执行这一步，详见[素材准备](docs/ASSET_PREPARATION.md)：

```powershell
py -m venv .venv
& '.\.venv\Scripts\python.exe' -m pip install pillow fonttools
.\tools\prepare_local_font.ps1 -FontFile 'C:\path\to\your-font.otf' -CjkFontFile 'C:\path\to\NotoSansSC.ttf'
.\tools\prepare_startup_audio.ps1 -InputFile 'C:\path\to\startup.mp3'
idf.py build
```

镜像布局、校验值及当前／历史镜像的区别见[发布说明](docs/RELEASING.md)。

本地启动音、用户音乐及包含它们的固件镜像请按各自授权范围使用。更多素材说明见 [docs/ASSET_PREPARATION.md](docs/ASSET_PREPARATION.md)。

## 目录

| 路径 | 用途 |
| --- | --- |
| `components/bsp/` | 屏幕、按键、音频等板级支持 |
| `main/` | 本地播放器、MP3 电台、共用 EVA 界面、设置、曲库和 Wi-Fi 上传/配网 |
| `assets/audio/` | 本地生成的启动音，不纳入 Git |
| `assets/preset_music/` | 可选的预置 FAM1 歌曲与 ETT1 歌名图，不纳入 Git |
| `tools/prepare_music.py`、`tools/package_factory.py` | 准备可删除预置歌曲并打包本地完整镜像 |
| `tools/prepare_local_font.ps1` | 在本地生成不纳入 Git 的字形、界面文字和上传网页 |
| `assets/promo/` | 根据用户提供的实机照片生成的三张 3:4 封面／玩法图，属于宣传图片而非原始实机截图 |
| `partitions.csv` | 2 MB 应用分区及约 5.9 MB 音乐分区 |
| `tests/` | 主机侧状态、编解码、曲库、HTTP、网页请求及打包测试 |

9 月历史版本在 COM14 验证过启动音、歌曲上传播放与歌名、重启持久性、重复进入热点、音量控制及 NERV 快速显示；当时三首歌的曲库校验约需 13 秒，期间保留 NERV 画面。这些观察不能代替 10 月版本的实机验收。原始日志和设备备份不纳入Git；当前验收摘要见[11月1日实机记录](docs/HARDWARE_TEST_20261101.md)；10月30日记录仅代表旧固件。

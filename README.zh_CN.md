# FoloToy EVA 音乐播放器

这是面向 FoloToy AI Passport（ESP32-C3、8 MB Flash）的离线播放器，当前源码版本为 `1.2.0-dev`。开机显示 NERV 图案并播放本地启动音；曲库保存在设备 Flash 中，用户可连接设备的开放 Wi-Fi 热点上传自己的音乐。

## 使用

1. 开机先保持背光关闭，NERV 图案绘制完成后点亮屏幕并播放启动音；结束后进入播放器。空曲库会显示 `NO TRACKS`。
2. 在停止或暂停状态长按 `DOWN`，进入传输页面。屏幕显示 `EVA-PLAYER-XXXX` 热点名。
3. 手机连接该热点，无需密码。浏览器打开 `http://192.168.4.1/`，选择音乐并上传。
4. 等页面提示传输完成，再在设备上长按 `DOWN` 退出传输页面。`OK` 播放/暂停，`UP`、`DOWN` 切歌。

在播放器长按 `UP` 进入 EVA 音量页；短按 `UP`／`DOWN` 以 5% 为步长调节音量，短按 `OK` 返回。音量范围为 0–100%，返回时保存，下次开机沿用。长按 `DOWN` 仍用于进入和退出热点页。

网页在手机浏览器中将音乐转为 12 kHz 或 8 kHz 单声道 FAM1/IMA ADPCM 后上传。单首最长 6 分钟、源文件最多 30 MB、转换后最多 2.5 MB，曲库最多 32 首；实际数量受剩余 Flash 空间限制。网页可以查看、删除歌曲，以及重新同步歌名图片。上传期间暂停播放，退出传输页面后从当前曲目开头播放。

完整出厂固件也可以预置歌曲：歌曲作为普通文件保存在同一个可写音乐分区，开机即可在曲库中看到，并可通过音乐管理页面删除、释放空间。删除后重启不会恢复；重新刷入含歌曲的完整出厂镜像才会恢复初始曲库。仅刷应用程序不会安装预置歌曲。生成和打包方法见[预置歌曲说明](docs/ASSET_PREPARATION.md#optional-deletable-factory-songs)。刷完整镜像会覆盖原有歌曲和设置。

其他页面修改曲库后，旧页面的删除／同步歌名请求会被拒绝并刷新列表，需要重新选择歌曲。删歌不再改名其他文件，重启允许文件槽位有空缺；新上传会复用空槽，因此可能插入列表前部。若删除在移除歌名图之后中断，歌曲仍能播放，可用“同步歌名”恢复标题。曲末等待期间长按 `UP` 调音量，不再取消自动下一曲。

设备固定文字、按钮及运行时英文和数字由构建者自备的字体在本地生成。上传网页随固件内置该字体的小型子集，手机打开页面后自动加载，用于网页文字和新歌名图，无需在手机上选择字体。子集未收录的字使用浏览器备用字体，重新同步歌名时页面会提示。已上传的旧歌名可点击“同步歌名”更新。字体原文件、生成的字形源码和网页字体子集均不上传 Git。

暂停时长按 `OK` 进入 NERV 待机页，短按 `OK` 返回。曲目结束后停留约 2 秒，再循环播放下一首。

播放器右上角“内部”旁的红条表示 CW2017 读取的电量：1–33% 一条、34–66% 两条、67–100% 三条；0% 或读数失败时不亮。约每 30 秒刷新一次。

## 构建

当前本地完整固件为 `release/FoloToy-EVA-player-3songs-fixed-20261001.bin`：完整 8 MiB，从 `0x0` 刷入，会覆盖原歌曲和设置。它包含引导程序、分区表、应用和三首可删除预置音乐：`残酷な天使のテーゼ（TV版）`、`Beautiful World`、`One Last Kiss`。同名 `.music.bin` 只有音乐分区，不带 `fixed` 的镜像是三项修复前的旧版；完整刷机只需使用带 `fixed` 的完整 BIN。这些生成文件不包含在源码仓库中。

ESP-IDF 5.5.4 构建应用 `0x19a2d0`，应用分区剩余 417,072 字节（约 20%），预置曲库剩余 1,978,368 字节。主机回归测试和最终镜像检查通过。2026-10-01 已将完整镜像写入 COM14（ESP32-C3 revision v1.1、8 MB Flash），数据哈希校验通过，并发出硬件复位。这仅确认烧录成功；本版播放、界面、多手机管理、物理断电恢复和运行时堆内存仍待实机验收。生成和打包命令见[素材准备](docs/ASSET_PREPARATION.md)。

使用 ESP-IDF 5.5.x。请自备有中日文字形、可在本机使用的字体与启动音；安装 Python 的 Pillow、fonttools 及 Node.js/npm，然后在构建前生成本地素材。克隆仓库后必须执行这一步，详见[素材准备](docs/ASSET_PREPARATION.md)：

```powershell
py -m venv .venv
& '.\.venv\Scripts\python.exe' -m pip install pillow fonttools
.\tools\prepare_local_font.ps1 -FontFile 'C:\path\to\your-font.otf'
.\tools\prepare_startup_audio.ps1 -InputFile 'C:\path\to\startup.mp3'
idf.py build
```

镜像布局、校验值及当前／历史镜像的区别见[发布说明](docs/RELEASING.md)。

本地启动音、用户音乐及包含它们的固件镜像请按各自授权范围使用。更多素材说明见 [docs/ASSET_PREPARATION.md](docs/ASSET_PREPARATION.md)。

## 目录

| 路径 | 用途 |
| --- | --- |
| `components/bsp/` | 屏幕、按键、音频等板级支持 |
| `main/` | 播放器、FAM1 解码、曲库、Wi-Fi 服务、上传页面 |
| `assets/audio/` | 本地生成的启动音，不纳入 Git |
| `assets/preset_music/` | 可选的预置 FAM1 歌曲与 ETT1 歌名图，不纳入 Git |
| `tools/prepare_music.py`、`tools/package_factory.py` | 准备可删除预置歌曲并打包本地完整镜像 |
| `tools/prepare_local_font.ps1` | 在本地生成不纳入 Git 的字形、界面文字和上传网页 |
| `assets/promo/` | 根据用户提供的实机照片生成的三张 3:4 封面／玩法图，属于宣传图片而非原始实机截图 |
| `partitions.csv` | 2 MB 应用分区及约 5.9 MB 音乐分区 |
| `tests/` | 主机侧状态、编解码、曲库、HTTP、网页请求及打包测试 |

9 月历史版本在 COM14 验证过启动音、歌曲上传播放与歌名、重启持久性、重复进入热点、音量控制及 NERV 快速显示；当时三首歌的曲库校验约需 13 秒，期间保留 NERV 画面。这些观察不能代替 10 月版本的实机验收。本地详细验收记录不纳入 Git。

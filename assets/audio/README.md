# Local Audio Assets

This directory is for locally generated player audio:

```text
track0.adpcm
track1.adpcm
track2.adpcm
```

Do not publish generated audio unless you have redistribution rights for the source recordings.

The current firmware expects 8 kHz mono custom IMA ADPCM files. See [../../docs/ASSET_PREPARATION.md](../../docs/ASSET_PREPARATION.md).

## 串口已确认

- 显示 240×320、LVGL、按键、存储和电池初始化成功；ES8311 初始化成功，恢复此前 65% 音量。
- 初始 15 秒熄屏触发；第一键仅唤醒，后续按键正常进入处理。
- 长按 UP 可切入电台，也记录到电台退出后本地音频输出以及再次长按 UP 进入电台；模式保存后，USB 复位自动恢复电台模式。
- 电台长按 DOWN 后，电台任务先释放 Wi-Fi/音频资源，再启动开放热点；手机连接并获得 DHCP 地址。
- 配网页扫描两轮，分别 found=14/shown=13 和 found=9/shown=8；扫描后恢复 AP。
- 热点内长按 OK 打开设置，保存日志为 mode=1、brightness=90、timeout=0、network=1；热点仍可连接并再次扫描。
- 本轮手机上传歌曲成功：1521062 字节、曲库 count=1。长按 DOWN 退出热点，按保存模式返回电台；长按 UP 切回本地，短按 OK 后 codec 输出 12000Hz/16bit/1ch，音量 90%。听感不由这些日志代替。
- 后续电台连接取得 IP，station=18 和 station=15 均返回 HTTP 200，MP3 启动 44100Hz/16bit/1ch 输出。期间长按 OK 打开并保存设置（brightness=90、timeout=0），未因此停止该段电台。
- station=15 从约 234.9 秒到 300.7 秒的观察窗口无重连；最近一段 elapsed_ms=30019、pcm_ms=30014、consumed_mismatch=0。这个短窗口不代表长期连续性或实听无卡顿。
- LVGL 本轮峰值 24000 字节，池总量约 46 KiB；电台起播空闲堆约 19 KiB、最大块 7680 字节，后续周期最大块 12288 字节。未出现内存分配失败日志。
- 最终采集未见 panic、assert、watchdog、堆损坏等崩溃错误。

## 限制和未验收项

- 早期 Wi-Fi reason=201/36 并退避重连；后续已连接并取得 HTTP 200，不记为仍未联网。手动切换时断连与任务释放不记为自发断流。
- 一次串口重新打开触发 USB_UART_CHIP_RESET，打断配网；这是采集操作造成的复位，不应记为固件自发崩溃。后续保持文件句柄、关闭 HUPCL 并接力读取；接力期间未再次出现 USB 复位。
- favicon 返回 404，以及一条 httpd_sock_err recv=11；随后上传成功，未据此判定配网或上传失败。
- 选台前后台站变为 18/15，但主入口不记录 double 事件，不能仅凭当前日志证明城市列表的全部导航。双击入口、版本行显示、屏幕无裁切和实际声音仍待用户反馈。
- 保存后的亮度/音量/熄屏完整重启恢复、断电后的歌曲保留、长时间/跨网络播放、100%音量无失真仍未单独验收。本轮停止监控时保留用户当前设置，未为验证恢复再次复位。

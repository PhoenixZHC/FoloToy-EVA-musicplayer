# 项目文档索引

当前正式版本为 1.2.1，更新于 2026-11-03。新版长按上切换本地/电台，长按下进入热点，长按 OK 进入设置；电台双击 OK 选择城市和电台。系统设置包括模式、亮度、音量、熄屏、网络、版本及帮助。

2026-11-03 本地源码新增 NERV 自动屏保及独立亮度设置，用户已确认 Logo、变暗和首次按键唤醒正常；同日修复首页配网模块的旧生成文件。随后发现历史构建配置与仓库不一致，已隔离生成配置并增加每次构建校验，重新构建和仅应用烧录通过。现有 11 月 1 日及当日较早镜像保留历史范围，最新证据见 [11月3日记录](HARDWARE_TEST_20261103.md)。

正式版为 **1.2.1**（无开发版后缀），ESP-IDF 5.5.4 按仓库配置构建通过。应用 1,999,696 字节，应用分区余 97,456 字节，静态 DRAM 余 112,422 字节；主机回归 47 项通过、0 失败。11 月 3 日相同播放修复代码的 1.2.0-dev 固件已仅应用烧录并校验，稳态 PCM/墙钟比例为 99.4%；用户随后确认“现在基本没有卡顿了”，取消 30 分钟长测。日志仍有 91–204 ms 喂音间隔及缓冲耗尽，不能承诺所有台站长期零卡顿。正式 1.2.1 本轮只重建和打包，没有重新刷机。详见[11月3日记录](HARDWARE_TEST_20261103.md)。

源码、工具、测试和公开验收摘要入仓库；完整BIN、字体及生成物、歌曲、设备备份、原始串口日志和本机CONTEXT保持本地忽略。完整BIN刷入会覆盖歌曲及设置；仅应用更新才保留它们。当前设备采用仓库配置应用更新，历史完整包的字节校验不证明它符合当前配置；屏幕和实际听感不由串口初始化日志代替。

正式版完整镜像：`release/FoloToy-EVA-1.2.1-full-8MB-20261103.bin`，8,388,608 字节，ESP32-C3 / 8MB / DIO / 80MHz，从 `0x0` 写入。由同一 build_linux_repo/ 的 bootloader、分区表和 1.2.1 应用合并，分段、版本和空白区校验通过。NVS、PHY 与音乐区均为 0xFF，无用户凭据或歌曲，保留内置启动音和界面字体。**刷入完整镜像会覆盖原有歌曲及设置**。本轮未刷入；BIN 和同名 SHA256/JSON 报告保留在 Git 忽略的 release/。完整 SHA256：`0974a5164f1dd115d597bb728bc9a7b3e542865fdd684656a0d49d87db0c4ac9`。

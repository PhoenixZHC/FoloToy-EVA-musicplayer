# EVA 网络电台开发文档

当前状态：2026-11-01，源代码版本 1.2.0-dev。网络电台直接集成在现有播放器中，保留本地 FAM1 音乐、启动音、上传、删除、歌名同步和音量功能，不另建子项目。

## 功能与操作

- 长按 OK 打开中文「系统设置」；上下选择项目，短按 OK 编辑或确认，长按 OK 或「保存并返回」保存退出。
- 「模式」选择本地播放器或网络电台；亮度为 10–100%，自动熄屏为常亮/15/30/60/120/300 秒。熄屏不停止音频，首个按键只唤醒屏幕。模式和设置保存后重启恢复。
- 「网络设置」打开现有上传热点。手机连接 EVA-PLAYER-XXXX，在 http://192.168.4.1/ 的独立电台配网面板扫描网络，点选 2.4 GHz Wi-Fi 后输入密码保存；也可打开 /radio/setup。无需手输网络名。
- 扫描最多读取 20 个接入点，同名保留最强信号；隐藏网络和仅 5 GHz 网络不显示，不支持的加密方式不可选。空结果和失败均有提示，开放网络密码留空。
- 保存后退出热点，在设置中选择「网络电台」并保存，即连接已保存网络与最近电台。旧的两次长按/NERV 待机入口已停用。
- 电台页短按 UP/DOWN 换台、OK 播放/暂停；双击 OK 选择城市，再选该城市电台，列表内长按 DOWN 返回上一级。主页面长按 UP 切换本地/电台并保存模式，长按 DOWN 停止当前音源并进入 EVA 热点；热点内长按 DOWN 退出。
- 音量 0–100%，每次 5%；0% 显式静音，0–70% 沿用原曲线，70%=-15 dB，100%=+6 dB（旧最高档为 0 dB）。本地和电台共用，保存退出设置时保存。用户确认新版「比之前好多了」；未单独确认具体试听档位及100%无失真。
- 配网只保存一组 SSID/密码到 NVS eva_radio；设备设置使用 eva_settings，现有音量持久化保持不变。凭据不返回网页、不写入日志。热点开放，应在可信环境中配置。

## EVA 界面

电台、热点、城市列表和设置通过 main/eva_player_frame.[ch] 共用原播放器顶栏、电量框及直角面板，沿用黑、橙、军绿、洋红配色。

- 左上原「再生时间」文字区显示两行：城市、分类和电台序号（如「上海」「音乐 02/08」）。
- 中央原数码计时框显示中文电台名；下一框显示直播状态。
- 最底部保留上台、播放、下台、暂停四格按钮，不再放说明文字。
- 中文设置包含模式、亮度、音量、自动熄屏、网络设置、版本、操作说明和保存并返回；每屏五行随选中项翻动。版本读取实际应用描述且不可编辑；原设置结构不变，音量仍沿用原 NVS 键。热点内保存设置保留热点，退出热点后恢复所选模式。按键说明集中在「操作说明」中。
- 中文使用本机生成的 Noto SC 子集，16/20 px、2 bpp，当前210个非ASCII字符；生成文件和字体不入Git。字体覆盖、帮助文字尺寸及台名最多三行的主机回归已通过。

## 模块与运行约束

| 模块 | 职责 |
| --- | --- |
| main/eva_player.c | 模式、中文设置、按键路由、音频资源切换 |
| main/eva_player_frame.[ch] | 本地/电台/设置共用EVA框架与电量 |
| main/eva_radio_view.[ch] | 电台布局、城市/电台列表 |
| main/eva_radio_catalog.[ch] | 稳定ID、城市、台名、来源与验证日期 |
| main/eva_radio_model.[ch] | 可主机测试的播放状态 |
| main/eva_radio_stream.[ch] | ICY元数据过滤、MP3帧边界、凭据校验 |
| main/eva_radio_config.[ch] | 配网和最近电台NVS |
| main/eva_radio_player.[ch] | STA、HTTP、MP3解码、I2S输出 |
| main/eva_radio_setup.c / .html | 独立配网页、扫描与JSON保存接口 |
| main/eva_settings* | 设置模型和NVS适配 |

- 电台只用I2S TX/DAC的bsp_audio_init_playback()，避免闲置RX DMA。原bsp_audio_init()保留全双工。模式切换等待原工作任务释放codec/I2S后再启动目标；设置未实际切模式时不停止当前音频。
- 上传SoftAP与STA播放互斥。/radio/scan仅临时APSTA扫描，不连接上游；无论成功或失败均释放结果并恢复AP。
- 单播放任务栈6144字节，输入4096字节，PCM4608字节；MP3按完整帧解码、保留未消费尾部，双声道下混单声道。
- 首次及读超时后在现有4 KiB输入区预缓冲3584字节（64 kbps约0.45秒），未增加音频分配。EAGAIN保留半帧，连续10秒无新数据才重连；其他读错误和EOF重连。连接/收流失败指数退避，最长30秒，可由退出取消。
- LVGL池48 KiB，TCP接收窗口11520字节，接收邮箱10，启用SACK；Wi-Fi省电关闭。保留lwIP线程内只读TCP诊断，不跨线程保存PCB指针。
- 分配失败记录原因并结束当前工作任务，不以无限重试隐藏内存不足。运行日志每30秒输出收流/PCM/堆、最大连续块和栈余量。
- 当前只支持MP3 HTTP直播，不支持HLS、节目单、在线更新目录或显示ICY曲名。HTTP流未加密；为控制证书校时和TLS内存需求，目录目前不使用HTTPS流。

## 参考实现与依赖

已于2026-10-27对照[leo0183/leo-radio](https://github.com/leo0183/leo-radio)（MIT）。借鉴配网与STA生命周期分离、全信道扫描/强信号选择和错误清理；本项目已有上传HTTP服务，因此复用服务并拆出独立配网模块。未移入自动定位、Radio Browser动态目录或多组网络保存。

参考项目用esp_audio_simple_dec处理跨HTTP块输入；本项目用frame decoder和显式残留处理，缓冲大小以ESP32-C3无PSRAM预算为准。

依赖ESP-IDF 5.5.4和espressif/esp_audio_codec 2.6.2，后者采用Espressif Modified MIT License，限结合Espressif产品使用；依赖许可不被本项目MIT覆盖。详见[NOTICE](../NOTICE.md)。

## 构建与验收状态

先按[素材准备](ASSET_PREPARATION.md)生成自备启动音、原播放器字形、网页及中文子集。已安装本机隔离环境的Linux入口：

    .venv/bin/python tools/idf_linux.py --check
    .venv/bin/python tools/idf_linux.py build size

该入口不安装依赖或替换素材，可用EVA_IDF_PATH、EVA_IDF_PYTHON_ENV、EVA_DEV_TOOLS、EVA_RISCV_BIN覆盖本机路径。运行Python测试限定tests目录并将.venv/bin加入PATH，使子进程能找到Node.js；其他机器先按硬件指南安装ESP-IDF，不能假定本机路径存在。

当前 11月1日应用为 0x1e8470（1999984字节），2 MiB应用分区余97168字节（5%），静态DRAM余112356字节；静态余量不等同于运行时空闲堆。已在ESP32-C3 revision v1.1、8 MB设备仅更新0x10000应用并校验，保留NVS和音乐。固件二进制、字体、启动音和原设备备份均不随源码发布。

本轮串口确认启动初始化、首键唤醒、模式往返、热点进出/扫描、上传1首、设置保存、本地12kHz和电台44.1kHz输出；两台HTTP200，一段约一分钟无重连。当前布局与实际听感未收到用户确认；旧版布局、听音和音量改善反馈保留在10月30日记录。完整主机检查为Python32通过/1跳过、独立C程序9通过、JS3脚本通过。
